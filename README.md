# LABII
Представьте, что это "набор букв" для создания дождя из символов, как в фильме "Матрица".

Простая аналогия:
Это как если бы вы делали искусственный снег для киносъемки:
У вас есть мешок со "снежинками" (символами)
Каждая снежинка — это либо 0, либо 1, либо Я
Компьютер случайно берет одну "снежинку" из мешка и рисует ее падающей

Что это дает на сайте:
Красивый фон — символы красиво падают, создавая атмосферу "кибер-мира"
Случайность — если бы везде были только нули, было бы скучно. А так получается разнообразная картинка
Русский акцент — буква "Я" добавляет местный колорит. Это как американский Matrix, но "наш", русский
Почему именно так много символов?
Много нулей и единиц — потому что это компьютерный код (как в фильме)
Еще больше букв "Я" — чтобы они чаще встречались и создавали узнаваемый узор
Всё в одной строке — так программе проще работать, всё в одном месте

По сути: Это просто "краски", которыми рисуется анимация фона. Как художник берет разные цвета из палитры, так и программа берет символы из этой строки.

Если бы вы хотели другой эффект, могли бы написать:
Только @#$% — получился бы "дождь из значков"
Только АБВГД — "дождь из букв"
Только смайлики 😀😎🚀 — было бы весело, но не по теме "Матрицы"
А здесь — золотая середина: и на "Матрицу" похоже, и по-русски смотрится.

Технические причины:
Пул символов для случайного выбора - при создании каждой "капли" дождя:
drop.textContent = characters.charAt(Math.floor(Math.random() * characters.length));
Случайно выбирается символ из этой строки, что позволяет избежать однообразия.

Контроль визуального веса - соотношение символов "0"/"1" и "Я" примерно 1:3 создает:
Частое появление "Я" для акцента
Редкое появление двоичных цифр для разнообразия
Уникальный визуальный паттерн

Оптимизация производительности - использование строки вместо массива символов:
Проще в написании и чтении
Меньше памяти занимает
Быстрый доступ по индексу через charAt()



Разбор самой анимации

Строка 1: for (let i = 0; i < 80; i++) {
"Давайте создадим 80 падающих капель"
let i = 0 — начинаем с нуля
i < 80 — сделаем ровно 80 капель (можно изменить число для большей/меньшей плотности)
i++ — после каждой капли переходим к следующей (i увеличивается на 1)

Строка 2: const drop = document.createElement('div');
"Создаем новую HTML-коробочку для нашей капли"
document.createElement('div') — создаем пустой блок на странице
drop — называем его "капля" (можно представить как маленькое окошко)

Строка 3: drop.style.position = 'absolute';
"Пусть капля может быть где угодно на экране"
absolute — означает "абсолютное позиционирование"
Капля не будет мешать другим элементам, будет поверх них

Строка 4: drop.style.left = Math.random() * 100 + 'vw';
"Поставим каплю в случайное место по горизонтали"
Math.random() — случайное число от 0 до 1 (например, 0.34)
* 100 — умножаем на 100 (получаем от 0 до 100)
+ 'vw' — добавляем "vw" (проценты от ширины экрана)
Пример: Math.random() * 100 = 45.6 → left: 45.6vw (на 45.6% от левого края)

Строка 5: drop.style.top = '-50px';
"Начнем выше экрана, чтобы капля "влетала" сверху"
-50px — 50 пикселей выше верхнего края экрана
Капля сначала не видна, потом появляется сверху

Строка 6: drop.style.color = '#00ff00';
"Сделаем каплю зеленой, как в фильме 'Матрица'"
#00ff00 — ярко-зеленый цвет (RGB: 0 красного, 255 зеленого, 0 синего)
Классический "матричный" цвет

Строка 7: drop.style.fontSize = (Math.random() * 8 + 12) + 'px';
"Сделаем размер капли случайным, но в разумных пределах"
Math.random() * 8 — случайное число от 0 до 8
+ 12 — прибавляем 12 (чтобы было не слишком мелко)
Диапазон: от 12px (0 + 12) до 20px (8 + 12)
Пример: если Math.random() = 0.5, то 0.5 * 8 + 12 = 16px

Строка 8: drop.style.opacity = Math.random() * 0.4 + 0.1;
"Сделаем каплю полупрозрачной, с разной степенью видимости"
Math.random() * 0.4 — случайное число от 0 до 0.4
+ 0.1 — прибавляем 0.1 (чтобы не было совсем невидимых)
Диапазон прозрачности: от 0.1 (почти прозрачные) до 0.5 (более заметные)

Строка 9: drop.style.animation =matrixRain ${Math.random() * 4 + 3}s linear infinite;
"Запустим анимацию падения с разной скоростью"
matrixRain — название CSS-анимации (описана где-то в стилях)
Math.random() * 4 + 3 — случайное время от 3 до 7 секунд
linear — равномерная скорость (без ускорения/замедления)
infinite — бесконечное повторение
Пример: matrixRain 5.3s linear infinite — падение за 5.3 секунды, повторять вечно

Строка 10: drop.style.animationDelay = Math.random() * 8 + 's';
"Разобьем старт капель, чтобы они начинались в разное время"
Math.random() * 8 — случайная задержка от 0 до 8 секунд
Без этого все капли начинали бы одновременно — было бы некрасиво
Пример: animationDelay: 3.2s — начнет падать через 3.2 секунды

Строка 11: drop.textContent = characters.charAt(Math.floor(Math.random() * characters.length));
"Выберем случайный символ из нашей строки"
characters.length — длина строки (сколько в ней символов)
Math.random() * characters.length — случайное число от 0 до длины строки
Math.floor(...) — округляем вниз до целого (например, 3.7 → 3)
characters.charAt(...) — берем символ под этим номером
Пример: если в строке 100 символов, берем случайный с 0 по 99 позицию

Строка 12: matrix.appendChild(drop);
"Добавляем готовую каплю на страницу"
matrix — это контейнер, куда складываем все капли
appendChild(drop) — "привязываем" созданную каплю к этому контейнеру
Без этой строки капля создалась бы, но не появилась на экране

Что в итоге получается:
Каждая из 80 капель:
Появляется в случайном месте сверху экрана
Падает с разной скоростью (3-7 секунд)
Начинается в разное время (задержка 0-8 секунд)
Имеет случайный размер (12-20px)
Имеет случайную прозрачность (10-50%)
Содержит случайный символ (0, 1 или Я)
Бесконечно повторяется — упала, появилась снова
